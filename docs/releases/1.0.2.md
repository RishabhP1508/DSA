patterns and the Playground. All 17 diagram families retain readable sizes,

one object when their representation matches; copies remain distinct. The
inspector separates names, types, keys and values, identifies cycles and aliases,
and pages large text and root-variable lists. Execution labels distinguish the
next statement, changes already recorded and exception unwinding.

The [repair audit](../reviews/visualization-inspector-repair.md) records all
findings, research and verification limits. Curriculum review hashes, Python
execution behavior and saved-progress formats remain unchanged.
